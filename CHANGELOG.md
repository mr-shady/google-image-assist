# Changelog

## 2.2.1

- Display the installed version directly from the extension manifest in settings.
- Add the project website and downloads link to settings.
- Publish an English GitHub README, project website, privacy page and installation guide.
- Include the project license in browser packages and verify Firefox background script packaging.

## 2.2.0

- Use a green Download Original Image button for new images and blue Download Again for matching successful downloads from the last 30 days.
- Detect completed downloads through browser-local history, including native Save Image As downloads.
- Refresh indicators on completion, preview changes and window focus without a separate history database.

## 2.1.0

- Introduce Image Assist branding, an English interface, layered extension icon, Solar SVG controls and a waiting spinner.
- Add linked developer credits and English store materials.

## 2.0.0

- Support Chrome and Firefox with separate Manifest V3 packages.
- Inspect original image bytes, format and dimensions instead of guessing from thumbnails.
- Reset metadata per image and prevent stale responses from overwriting the current selection.
- Add search-size preferences, card placement, dark mode and download-error handling.
